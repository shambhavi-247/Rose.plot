# Rose.plot
This repository holds the code and results for a Rose Curve plot generated using MATLAB. The Rose Curve, also known as the Rhodonea curve, is a classic mathematical shape created using polar coordinates. Completing this project was a great way for me to understand the basics of scientific computing and the power of visualization.
# Introduction
This repository contains the code I wrote in **MATLAB** to generate a beautiful **Rose Curve** plot. It was a great way to practice the basic plotting functions and learn how to use Git.

## 💻 The Code

* **File Name:** `rose1.m` (or whatever you named your file)
* **Purpose:** The script uses **polar coordinates** ($$r, \theta$$) and a simple formula ($$r = \cos(k\theta)$$) to calculate the shape.
* **Key MATLAB Command Used:** I used the **`polarplot`** function to visualize the shape, which was a new feature I learned!

## 🚀 How to Run the Code

If you have MATLAB installed, you can try it yourself!

1.  Download the `rose1.m` file.
2.  Open MATLAB and change the directory to where you saved the file.
3.  Type the file name in the Command Window:
    ```matlab
    Rose_Curve_Generator
    ```
4.  The plot should appear in a new figure window!
